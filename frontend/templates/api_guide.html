API Integration Documentation

This document describes how Django Frontend consumes REST APIs from the Java Spring Boot Backend.

1. Architecture Overview

The Django frontend communicates with the Java Spring Boot backend through HTTP REST APIs:


Django Frontend → HTTP Requests → Java Spring Boot Backend → PostgreSQL Database
        ↑                                      ↓
        └──────────── HTTP Responses ────────┘
2. API Client Implementation

Location: apps/core/api_client.py

The APIClient class handles all HTTP communication:

from apps.core.api_client import api_client

# All methods use the api_client singleton instance
response = api_client.login(username, password)
response = api_client.get_products(token, page=1, size=10)
response = api_client.create_bill(token, bill_data)
3. Authentication Flow
  1. Login: User submits credentials to Django login view
  2. API Call: Django calls api_client.login(username, password)
  3. Backend Response: Java backend returns JWT token and user info
  4. Session Storage: Token stored in Django session
  5. Subsequent Requests: Token included in Authorization header for all API calls
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

5. Error Handling

API errors are handled gracefully:

response = api_client.get_product_by_id(token, 999)

if response and 'data' in response:
    product = response['data']
    # Process product
else:
    # Handle error - response will be None if API call failed
    messages.error(request, 'Product not found')
Common Error Scenarios:
  • Connection Error: Backend API unreachable
  • Timeout Error: Request takes too long (configurable timeout)
  • Invalid JSON: Response is not valid JSON
  • HTTP Errors: 400, 401, 403, 404, 500, etc.

7. Configuration

Backend API URL: BACKEND_API_URL in config/settings.py

BACKEND_API_URL = os.getenv('BACKEND_API_URL', 'http://localhost:8080/api/v1')

API Timeout: BACKEND_API_TIMEOUT (in seconds)

BACKEND_API_TIMEOUT = int(os.getenv('BACKEND_API_TIMEOUT', '10'))

Configure in .env:

BACKEND_API_URL=http://localhost:8080/api/v1
BACKEND_API_TIMEOUT=10
8. View Integration Example
from apps.core.api_client import api_client
from django.shortcuts import render
from apps.core.decorators import login_required_custom

@login_required_custom
def product_list(request):
    token = request.session.get('token')
    page = request.GET.get('page', 1)
    
    # Call API
    response = api_client.get_products(token, page=int(page), size=10)
    
    # Extract data
    products = []
    if response and 'data' in response:
        data = response['data']
        if isinstance(data, dict) and 'content' in data:
            products = data['content']
    
    # Render template
    context = {
        'products': products,
        'current_page': int(page),
    }
    
    return render(request, 'products/list.html', context)
